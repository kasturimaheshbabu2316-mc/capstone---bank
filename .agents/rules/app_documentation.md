# Agent Rule: Consolidated Application Source Code Document ("app")

## Core Directive
Whenever writing, creating, or modifying Python (`.py`) files in a project, you MUST always compile and maintain all `.py` files inside a single consolidated document named **`app`** (`app.md` / `doc/app.md`).

## Requirements
1. **Folder Hierarchy Preservation:** Group each `.py` file under its respective folder (e.g., `rag/`, `agents/`, `api/`, `review/`, `governance/`, `evaluation/`).
2. **Complete Source Code:** Include the full, unabridged code for each `.py` module with syntax highlighting, file path, and a concise summary.
3. **Purpose:** Enables rapid navigation, quick file inspection, and streamlined project comprehension in a single unified view.
